LightSpeed는 ML 기반 프록시 선택으로 게임 트래픽을 가장 빠른 경로로 라우팅하는 오픈소스 네트워크 최적화 프로그램입니다. 구독 없음. 익명 집계 텔레메트리는 기본으로 켜져 있고 언제든 끌 수 있습니다. 그냥 더 낮은 지연 시간.

작동 방식

세 단계. 그게 전부. 계정도, 설정 파일도, 잡소리도 없음.

1

LightSpeed 실행

게임 전에 가벼운 클라이언트를 실행하세요. 23개의 내장 프로필을 자동 감지합니다: Fortnite, CS2, CS:GO Legacy, Dota 2, Rust, Valorant, Apex Legends, Overwatch 2, League of Legends, PUBG, MapleStory, Genshin Impact, Rocket League, World of Tanks, Dead by Daylight, Bodycam, Roblox, Project Zomboid, WARDOGS, Minecraft (Bedrock 및 Java), Hunt: Showdown, Rainbow Six Siege.

2

ML이 경로를 선택

ML 모델이 프록시 노드 전반의 지연 시간, 지터, 패킷 손실을 분석한 뒤 단일 추론으로 가장 빠른 경로를 선택합니다. 런타임 기준 마이크로초 단위입니다.

3

더 낮은 핑으로 플레이

게임 트래픽은 패킷 변조 없이 투명하게 우회되며, 안티치트 호환성을 고려해 설계되었습니다. 그냥 더 빠른 패킷.

왜 LightSpeed인가

왜 LightSpeed인가?

LightSpeed를 특별하게 만드는 것들.

진짜 무료

"무료 체험"식 무료가 아닙니다. "프리미엄"식 무료도 아닙니다. 영원히 0원이라는 뜻의 무료. 커뮤니티 릴레이 네트워크는 커뮤니티가 호스팅하고 후원자 자금으로 운영되며, 무료 등급 클라우드 VPS 크레딧으로 직접 프록시를 돌릴 수도 있습니다. 중간상도, 구독도, 숨은 비용도 없습니다. 영원히.

오픈소스

모든 코드 한 줄 한 줄이 GitHub에 있습니다. 감사하고, 포크하고, 개선하세요. 블랙박스도, 정체불명 바이너리도, 우리를 믿으라는 식의 보안도 없습니다.

ML 기반

모델이 실제 지연 시간 데이터, 시간대, 네트워크 상태로부터 어떤 경로가 가장 빠른지 학습합니다. 그냥 "가장 가까운 서버를 고르기"가 아닙니다.

안티치트 호환성을 고려한 설계

LightSpeed는 게임 패킷이나 메모리를 절대 변조하지 않습니다. 패킷이 지나는 경로만 바꾸고 페이로드는 그대로 둡니다. EAC, VAC, Vanguard의 탐지 모델을 건드리지 않고 함께 작동하도록 만들어졌습니다.

개인정보 우선

계정이 필요하지 않습니다. 익명 집계 텔레메트리는 기본으로 켜져 있으며 --no-telemetry 또는 GUI 체크박스로 언제든 끌 수 있습니다. 릴레이의 인증되지 않은 /telemetry 엔드포인트로 일반 텍스트 HTTP를 통해 집계된 지연 시간 지표만 전송합니다. IP 주소, 식별자, 패킷 내용은 포함하지 않습니다. 셀은 최소 3건의 보고가 모일 때까지 공개되지 않습니다(사람 수가 아니라 보고 수를 셉니다). 안티치트가 트래픽을 검사할 수 있도록 터널은 의도적으로 암호화하지 않으며, 게임 서버에는 항상 실제 IP가 보입니다. 릴레이 운영자는 기술적으로 전송 중인 트래픽을 관찰하거나 수정할 수 있으므로 LightSpeed는 프라이버시나 익명화 도구가 아닙니다. 기밀성이 필요하다면 직접 릴레이를 운영하세요. 개인정보 처리방침를 참고하세요.

Rust로 제작

빠르고, 메모리 안전하고, 제로 비용 추상화. 전체 스택(클라이언트, 프록시, 프로토콜)은 비동기 Tokio와 QUIC를 사용하는 순수 Rust입니다.

토큰 인증

클라이언트는 QUIC 제어 평면으로 등록하고 모든 데이터 평면 패킷에 세션 토큰을 찍습니다. 프록시는 패킷마다 (IP, token)을 검증합니다. 등록되지 않은 발신자는 폐기됩니다. require_auth은 기본으로 켜져 있습니다.

TCP 폴백

클라이언트와 프록시 사이의 터널은 기본적으로 UDP를 사용하지만, UDP를 차단하는 네트워크(호텔, 카페, 제한적인 ISP)에서는 TCP(--tcp)로 전환합니다. 낮은 오버헤드의 최적화는 그대로면서 호환성이 넓어집니다.

FAQ

이게 왜 무료죠? 함정은 없나요?

숨은 조건은 없습니다. 커뮤니티 릴레이 네트워크는 커뮤니티가 호스팅하고 스폰서가 자금을 지원하므로, 직접 아무것도 운영하지 않고도 클라이언트를 설치해 플레이할 수 있습니다. 소프트웨어는 완전한 오픈 소스이며, 원한다면 직접 프록시를 운영할 수도 있습니다. Vultr는 신규 계정에 300달러 무료 크레딧을 제공하고 Oracle Cloud는 영구 무료 티어가 있습니다. 우리는 당신의 데이터를 판매하지 않습니다. 익명 집계 텔레메트리는 기본으로 켜져 있으며 언제든 끌 수 있습니다. 개인정보 처리방침를 참고하세요.

이거 쓰면 밴당하나요?

LightSpeed는 주요 안티치트 시스템과 호환되도록 설계되었습니다: 게임 파일이나 메모리를 변조하지 않고, 게임 프로세스에 후킹하지 않으며, IP를 숨기지도 않습니다. 이 계열의 경로 최적화 도구는 수년간 사용되어 왔습니다. 다만 안티치트 정책과 이용약관은 퍼블리셔마다 정하며 언제든 바뀔 수 있으므로, 어떤 도구도 밴이 절대 발생하지 않는다고 보장할 수 없습니다. 플레이 전에 해당 게임의 약관을 확인하세요.

이게 실제로 핑을 얼마나 줄여주나요?

위치와 ISP에 따라 다릅니다. ISP가 트래픽을 최적이 아닌 경로로 보낸다면(아주 흔합니다) LightSpeed가 핑을 의미 있게 깎아줄 수 있습니다. ISP가 이미 최적 라우팅을 하고 있다면 개선은 미미할 수 있습니다. 모델은 최선의 경로를 고르고, 직접 경로가 가장 빠르면 직접 경로를 씁니다. 위의 대표 수치는 실제 클라이언트 측정에서 나온 추정값입니다: 클라이언트의 게임 서버까지 ICMP 왕복과 터널을 거친 게임 트래픽 왕복의 차이입니다. ICMP와 게임 트래픽은 서로 다른 계측 도구이므로, 인게임 지연 시간의 약속이 아니라 신호로 읽으세요.

LightSpeed가 인터넷을 더 빠르게 해주나요?

아니요. LightSpeed가 트래픽을 더 빠르게 만들 수는 없습니다. 물리 법칙을 이길 수는 없죠. 대신 트래픽을 사용 가능한 가장 빠른 경로로 선제적으로 우회시켜 혼잡과 불필요하게 긴 경로를 피합니다. ISP가 이미 깨끗한 경로를 갖고 있거나 프록시 위치가 나쁘면 개선이 거의 또는 전혀 없을 수 있습니다.

프록시를 쓰면 왜 핑이 더 높아지나요?

보통 둘 중 하나입니다. (1) 릴레이가 게임 서버보다 멀어서 추가 홉이 지연을 더하거나, (2) 릴레이의 데이터 센터가 인터넷 백본에 잘 연결되지 않은 경우입니다. 프록시 위치는 매우 중요합니다. 즉 데이터 센터가 주요 백본·피어링 지점에 얼마나 가까운지입니다. 실제 경로는 BGP 피어링 계약과 ISP 우선순위에도 좌우되며, 이는 당신도 LightSpeed도 통제할 수 없습니다. 나에게 가까운 프록시가 아니라 게임 서버에 가장 가까운 프록시를 선택하세요. 경로가 어떻게 동작하는지 대화형으로 보려면 경로 시각화를 참고하세요.

어떤 게임이 지원되나요?

현재 22개 게임: Fortnite, CS2, CS:GO Legacy, Dota 2, Rust, Valorant, Apex Legends, Overwatch 2, League of Legends, PUBG, MapleStory, Genshin Impact, Rocket League, World of Tanks, Dead by Daylight, Bodycam, Roblox, Project Zomboid, WARDOGS, Minecraft, Hunt: Showdown, Rainbow Six Siege에 프로필이 내장되어 있습니다. --game <name>로 실행하거나 자동 감지에 맡기면 됩니다. 그 밖의 UDP 기반 게임은 수동 포트 설정으로 사용할 수 있습니다.

제 데이터는 안전한가요?

익명 집계 텔레메트리는 기본으로 켜져 있습니다. 계정도, 가입도, 개인 데이터도 없습니다. 집계된 네트워크 지표(지연 시간 백분위, 지터, FEC 카운터)만 릴레이의 인증되지 않은 /telemetry 엔드포인트로 일반 텍스트 HTTP를 통해 전송합니다. IP 주소, 식별자, 패킷 내용은 포함하지 않습니다. 셀은 최소 3건의 보고가 모일 때까지 공개되지 않습니다(사람 수가 아니라 보고 수를 셉니다). --no-telemetry, lightspeed.toml의 telemetry = false, 또는 GUI 체크박스로 언제든 끌 수 있습니다. 오버헤드를 늘리지 않기 위해 모든 트래픽은 암호화되지 않은 채로 통과합니다. 개인정보 처리방침와 데이터 사전를 참고하세요.

프록시 노드는 어떻게 구하나요?

가장 쉬운 방법은 아무것도 하지 않는 것입니다. 기본 클라이언트는 커뮤니티 릴레이 네트워크를 사용하며, 서명된 레지스트리에서 가장 빠른 릴레이를 자동으로 찾습니다. 직접 노드를 운영하고 싶다면 Vultr에서 월 5~6달러 VPS를 만들고(또는 Oracle Cloud 무료 티어 이용) 저장소의 setup-new-node.sh 스크립트를 실행한 뒤 클라이언트를 자신의 IP로 지정하세요. 약 5분이면 됩니다. 데이터·제어·헬스 포트는 프록시 설정의 [network] 섹션에서 구성합니다. 전체 안내는 infra/README.md를 참고하세요.

왜 Rust인가요?

Rust는 메모리 안전성 보장과 함께 C/C++의 성능을 제공합니다. 초당 수천 개의 패킷을 처리하는 지연 시간이 중요한 네트워크 도구에는 제로 오버헤드 추상화가 필요합니다. Rust의 비동기 생태계(Tokio)와 QUIC 라이브러리(quinn)는 세계 최고 수준입니다.

ML 라우팅은 어떻게 작동하나요?

11개 특성(현재 지연 시간, 과거 p50/p95, 지터, 패킷 손실, 홉 수, 시간대, 프록시 부하, 지리적 거리)으로 네트워크 지연 시간 데이터에 Random Forest 모델을 학습시킵니다. 모델은 단일 추론으로 어떤 프록시 경로가 가장 빠를지 예측하며, 런타임 기준 마이크로초 단위입니다. 모델은 학습할 때마다 홀드아웃 테스트 분할에 대한 자체 R², MAE, RMSE를 보고합니다; 수치는 학습 데이터에 따라 달라지므로 고정된 값을 공개하지 않습니다.
