为什么选 LightSpeed？

这些就是 LightSpeed 与众不同之处。

真的免费

不是 "免费试用" 那种免费。不是 "freemium" 那种免费。是永远零美元。社区中继网络由社区托管、赞助商资助，你仍然可以用免费额度的云 VPS 跑自己的代理。没有中间商，没有订阅，没有隐藏费用。永远。

开源

每一行代码都在 GitHub 上。审计它、fork 它、改进它。没有黑盒，没有神秘二进制，没有 "信我就好" 的安全。

ML 驱动

模型从真实延迟数据、时段和网络状况中学习哪条路由最快。不是单纯 "挑最近的服务器"。

为反作弊兼容而设计

LightSpeed 从不改动游戏数据包或内存。它只改变数据包走的路由，载荷原封不动。它的设计目标就是和 EAC、VAC、Vanguard 共存，不触发它们的检测模型。

隐私优先

No account required. Anonymous aggregate telemetry is on by default and can be turned off any time with --no-telemetry or the GUI checkbox. It sends only aggregate latency metrics over plaintext HTTP to the relay's unauthenticated /telemetry endpoint: no IP addresses, no identifiers, no packet contents. A cell is suppressed until it has at least 3 reports (this counts reports, not distinct people). The tunnel is intentionally unencrypted so anti-cheat systems can inspect the traffic, and game servers always see your real IP. A relay operator can technically observe or modify traffic in transit, so LightSpeed is not a privacy or anonymity tool. If you need confidentiality, self-host your own relay. See the Privacy Policy.

用 Rust 构建

快、内存安全、零开销抽象。整套技术栈（客户端、代理、协议）都是纯 Rust，配异步 Tokio 和 QUIC。

令牌认证

客户端通过 QUIC 控制面注册，并在每个数据面数据包里盖上会话令牌。代理会逐包校验。未注册的发送方直接丢弃。默认开启。

TCP 回退

客户端到代理的隧道默认走 UDP，但在封禁 UDP 的网络上会切到 TCP（）：酒店、咖啡馆、限制严格的 ISP。同样低开销的优化，兼容面更广。

疑问

常见问题

这怎么可能是免费的？套路在哪？

There is no catch. The community relay network is community-hosted and sponsor-funded, so you can install the client and play without running anything yourself. The software is fully open source, and you can still self-host your own proxy if you prefer: Vultr gives new accounts $300 free credit and Oracle Cloud has a free tier forever. We don't sell your data. Anonymous aggregate telemetry is on by default and can be turned off any time; see the 隐私政策.

这会不会让我被封号？

LightSpeed 的设计目标就是兼容主流反作弊系统：它不改动游戏文件或内存，不挂钩游戏进程，也不隐藏你的 IP。这一类路由优化器已经被用了好几年。不过，反作弊策略和服务条款由各家发行商制定，随时可能变化，所以没有任何工具能保证永远不会封号。玩之前请查阅对应游戏的条款。

这到底能降多少延迟？

取决于你的位置和 ISP。如果你的 ISP 把流量绕了远路（很常见），LightSpeed 能明显削掉一截延迟。如果 ISP 的路由本来就很好，提升可能很小。模型会挑最好的路由，如果直连最快就直连。上面那个主推数据是根据真实客户端测量估算的：它是客户端到游戏服务器的 ICMP 往返时间和走隧道的游戏流量往返时间之差。ICMP 和游戏流量是两种不同的测量手段，所以把它当作一个信号，而不是游戏内延迟的承诺。

LightSpeed 会让我的网速变快吗？

不会。LightSpeed 没法让你的流量跑得更快，它跑不赢物理定律。它做的是主动把你的流量引到当前可用的最快路径上，避开拥塞和没必要的绕路。如果你的 ISP 本来就有干净的线路，或者你的代理节点位置很糟，那基本看不到提升。

为什么用了代理延迟反而更高？

Usually one of two things: (1) the proxy is farther from the game server than your direct path, so the extra hop adds latency, or (2) the proxy's data center isn't well-connected to the internet backbone. Proxy placement matters a lot: how close the datacenter sits to major backbone/peering points. Real-world routing is also governed by BGP peering contracts and ISP prioritization, which neither you nor LightSpeed control. Pick the proxy closest to the 游戏服务器, not closest to you. For an interactive look at how routing works, see the 路由可视化.

我的数据安全吗？

Anonymous aggregate telemetry is on by default. No accounts, no registration, and no personal data. It sends only aggregate network metrics (latency percentiles, jitter, FEC counters) over plaintext HTTP to the relay's unauthenticated /telemetry endpoint: no IP addresses, no identifiers, and no packet contents. A cell is suppressed until it has at least 3 reports (this counts reports, not distinct people). Turn it off any time with --no-telemetry, telemetry = false in lightspeed.toml, or the GUI checkbox. All traffic passes through unencrypted to avoid adding overhead. See the 隐私政策 and 数据字典.

怎么获得代理节点？

The easiest path is to do nothing: the default client experience uses the community relay network, and your client auto-discovers the fastest relay from the 签名注册表. If you want to run your own node instead, spin up a $5-6/mo VPS on Vultr (or use Oracle Cloud free tier), run the setup-new-node.sh script in the repo, and point your client at your own IP. It takes about 5 minutes. Data, control, and health ports are configurable via the [network] section of the proxy config. See infra/README.md for the full guide.

为什么用 Rust？

Rust 给我们 C/C++ 的性能，还带内存安全保证。对一个每秒要处理成千上万个数据包的延迟敏感网络工具来说，我们需要零开销抽象。Rust 的异步生态（Tokio）和 QUIC 库（quinn）都是世界级的。

ML 路由是怎么工作的？

我们用网络延迟数据训练一个随机森林模型，含 11 个特征：当前延迟、历史 p50/p95、抖动、丢包、跳数、时段、代理负载和地理距离。模型一次推理就能预测哪条代理路由最快，运行时的测量单位是微秒。模型每次训练都会在留出的测试集上报告自己的 R²、MAE 和 RMSE；这个数字随训练数据变化，所以我们不公布固定值。
