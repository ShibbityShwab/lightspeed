How It Works

Three steps. That's it. No accounts, no config files, no BS.

1

Launch LightSpeed

Run the lightweight client before your game. It auto-detects 18 built-in profiles: Fortnite, CS2, CS:GO Legacy, Dota 2, Rust, Valorant, Apex Legends, Overwatch 2, League of Legends, PUBG, MapleStory, Genshin Impact, Rocket League, World of Tanks, Dead by Daylight, Bodycam, Roblox, and Project Zomboid.

2

ML Picks Your Route

The ML model analyzes latency, jitter, and packet loss across your proxy nodes, then selects the fastest path in a single inference pass, measured in microseconds at runtime.

Play with Lower Ping

Your game traffic is transparently rerouted with no packet modification, designed for anti-cheat compatibility. Just faster packets.

Why LightSpeed

Why LightSpeed?

We're not another ExitLag clone. Here's what makes us different.

Actually Free

Not "free trial" free. Not "freemium" free. Free as in zero dollars forever. The community relay network is community-hosted and sponsor-funded, and you can still run your own proxy on free-tier cloud VPS credits. No middleman, no subscription, no hidden cost. Ever.

Open Source

Every line of code is on GitHub. Audit it, fork it, improve it. No black boxes, no mystery binaries, no trust-us-bro security.

ML-Powered

The model learns which route is fastest from real latency data, time of day, and network conditions. Not just "pick the closest server."

Designed for Anti-Cheat Compatibility

LightSpeed never modifies game packets or memory. It only changes the route your packets take, and the payload is untouched. It is built to work alongside EAC, VAC, and Vanguard without triggering their detection models.

Privacy First

No account required. Anonymous aggregate telemetry is on by default and can be turned off any time with --no-telemetry or the GUI checkbox. It sends only aggregate latency metrics over plaintext HTTP to the relay's unauthenticated /telemetry endpoint: no IP addresses, no identifiers, no packet contents. A cell is suppressed until it has at least 3 reports (this counts reports, not distinct people). The tunnel is intentionally unencrypted so anti-cheat systems can inspect the traffic, and game servers always see your real IP. A relay operator can technically observe or modify traffic in transit, so LightSpeed is not a privacy or anonymity tool. If you need confidentiality, self-host your own relay. See the Privacy Policy.

Built in Rust

Fast, memory-safe, zero-cost abstractions. The entire stack (client, proxy, protocol) is pure Rust with async Tokio and QUIC.

Token Authenticated

Clients register over a QUIC control plane and stamp a session token into every data-plane packet. The proxy validates (IP, token) per packet. Unregistered senders are dropped. require_auth is on by default.

TCP Fallback

The client to proxy tunnel defaults to UDP, but switches to TCP (--tcp) on networks that block UDP: hotels, coffee shops, restrictive ISPs. Same low-overhead optimization, broader compatibility.

Questions

FAQ

How is this free? What's the catch?

There is no catch. The community relay network is community-hosted and sponsor-funded, so you can install the client and play without running anything yourself. The software is fully open source, and you can still self-host your own proxy if you prefer: Vultr gives new accounts $300 free credit and Oracle Cloud has a free tier forever. We don't sell your data. Anonymous aggregate telemetry is on by default and can be turned off any time; see the Privacy Policy.

Will this get me banned?

LightSpeed is designed to be compatible with major anti-cheat systems: it does not modify game files or memory, does not hook game processes, and does not hide your IP. Route optimizers in this class have been used for years. That said, anti-cheat policy and terms of service are set by each publisher and can change at any time, so no tool can guarantee a ban will never occur. Check the relevant game's terms before you play.

How much will this actually reduce my ping?

It depends on your location and ISP. If your ISP routes your traffic through suboptimal paths (very common), LightSpeed can cut a meaningful amount off your ping. If your ISP already has optimal routing, the improvement may be minimal. The model picks the best route, or direct if that's fastest. The hero stat above is an estimate from real client measurements: it is the difference between the client's ICMP round trip to the game server and its tunnelled game-traffic round trip. ICMP and game traffic are different instruments, so read it as a signal, not a promise of in-game latency.

Does LightSpeed make my internet faster?

No. LightSpeed can't make your traffic go faster. It can't outrun physics. What it does is proactively route your traffic onto the fastest available path, avoiding congestion and needlessly long routes. If your ISP already has a clean route, or your proxy is badly placed, you'll see little to no improvement.

Why is my ping higher when I use a proxy?

Usually one of two things: (1) the proxy is farther from the game server than your direct path, so the extra hop adds latency, or (2) the proxy's data center isn't well-connected to the internet backbone. Proxy placement matters a lot: how close the datacenter sits to major backbone/peering points. Real-world routing is also governed by BGP peering contracts and ISP prioritization, which neither you nor LightSpeed control. Pick the proxy closest to the game server, not closest to you. For an interactive look at how routing works, see the Route Visualizer.

What games are supported?

Currently 18 games: Fortnite, CS2, CS:GO Legacy, Dota 2, Rust, Valorant, Apex Legends, Overwatch 2, League of Legends, PUBG, MapleStory, Genshin Impact, Rocket League, World of Tanks, Dead by Daylight, Bodycam, Roblox, and Project Zomboid all have built-in profiles. Just run with --game <name> or let auto-detection pick it up. Any other UDP-based game can work with manual port configuration.

Is my data safe?

Anonymous aggregate telemetry is on by default. No accounts, no registration, and no personal data. It sends only aggregate network metrics (latency percentiles, jitter, FEC counters) over plaintext HTTP to the relay's unauthenticated /telemetry endpoint: no IP addresses, no identifiers, and no packet contents. A cell is suppressed until it has at least 3 reports (this counts reports, not distinct people). Turn it off any time with --no-telemetry, telemetry = false in lightspeed.toml, or the GUI checkbox. All traffic passes through unencrypted to avoid adding overhead. See the Privacy Policy and Data Dictionary.

How do I get a proxy node?

The easiest path is to do nothing: the default client experience uses the community relay network, and your client auto-discovers the fastest relay from the signed registry. If you want to run your own node instead, spin up a $5-6/mo VPS on Vultr (or use Oracle Cloud free tier), run the setup-new-node.sh script in the repo, and point your client at your own IP. It takes about 5 minutes. Data, control, and health ports are configurable via the [network] section of the proxy config. See infra/README.md for the full guide.

Why Rust?

Rust gives us the performance of C/C++ with memory safety guarantees. For a latency-critical network tool that handles thousands of packets per second, we need zero-overhead abstractions. Rust's async ecosystem (Tokio) and QUIC libraries (quinn) are world-class.

How does the ML routing work?

We train a Random Forest model on network latency data with 11 features: current latency, historical p50/p95, jitter, packet loss, hop count, time of day, proxy load, and geographic distance. The model predicts which proxy route will be fastest in a single inference pass, measured in microseconds at runtime. The model reports its own R², MAE, and RMSE against a held-out test split each time it trains; the figure varies with the training data, so we do not publish a fixed number.
