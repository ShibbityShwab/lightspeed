LightSpeedを選ぶ理由

なぜLightSpeedなのか?

LightSpeedが他と違う点はこちら。

本当に無料

「無料トライアル」的な無料ではありません。「フリーミアム」的な無料でもありません。ずっと0円という意味の無料です。コミュニティリレーネットワークはコミュニティがホストし、スポンサーが資金を出しています。無料枠のクラウドVPSクレジットで自分のプロキシを動かすこともできます。仲介業者なし、サブスクなし、隠れた費用なし。ずっと。

オープンソース

コードはすべてGitHubにあります。監査し、フォークし、改良してください。ブラックボックスも、正体不明のバイナリも、「信じてくれ」なセキュリティもありません。

ML搭載

モデルは実際の遅延データ、時間帯、ネットワーク状況から最速のルートを学習します。「一番近いサーバーを選ぶ」だけではありません。

アンチチート互換を重視した設計

LightSpeedはゲームのパケットやメモリを決して改変しません。変えるのはパケットが通るルートだけで、ペイロードには触れません。EAC、VAC、Vanguardの検知モデルを作動させずに併用できるよう作られています。

プライバシー優先

アカウントは不要です。匿名の集計テレメトリーは既定で有効で、--no-telemetry または GUI のチェックボックスでいつでもオフにできます。送信するのは集計されたレイテンシ指標のみで、リレーの認証なし /telemetry エンドポイントへ平文 HTTP で送られます。IP アドレス、識別子、パケット内容は含みません。セルは 3 件以上の報告が集まるまで公開されません（数えるのは報告数であり、人数ではありません）。アンチチートが通信を検査できるよう、トンネルは意図的に暗号化していません。ゲームサーバーには常に実際の IP が見えます。リレー運営者は技術的には通信を傍受・改変できます。つまり LightSpeed はプライバシーや匿名化のツールではありません。機密性が必要なら、ご自身でリレーを立ててください。詳細は プライバシーポリシー をご覧ください。

Rustで開発

高速、メモリ安全、ゼロコスト抽象化。スタック全体 (クライアント、プロキシ、プロトコル) がasync TokioとQUICを使った純粋なRustです。

トークン認証

クライアントは QUIC 制御プレーンで登録し、データプレーンの各パケットにセッショントークンを付与します。プロキシはパケットごとに (IP, token) を検証します。未登録の送信元は破棄されます。require_auth は既定で有効です。

TCPフォールバック

クライアントとプロキシ間のトンネルは既定で UDP を使用しますが、UDP を遮断するネットワーク（ホテル、カフェ、制限の厳しい ISP）では TCP（--tcp）に切り替わります。低オーバーヘッドの最適化はそのままに、対応範囲が広がります。

質問

FAQ

なぜ無料なの? 裏はある?

裏はありません。コミュニティリレーネットワークはコミュニティがホストし、スポンサーが資金を提供しているため、自分で何も動かさずにクライアントをインストールして遊べます。ソフトウェアは完全にオープンソースで、自分でプロキシを運用したい場合も可能です。Vultr は新規アカウントに 300 ドルの無料クレジットを提供し、Oracle Cloud には永続的な無料枠があります。あなたのデータを販売することはありません。匿名の集計テレメトリーは既定で有効で、いつでもオフにできます。詳しくは プライバシーポリシー をご覧ください。

これでBANされない?

LightSpeedは主要なアンチチートシステムとの互換を前提に設計されています。ゲームファイルやメモリを改変せず、ゲームプロセスにフックせず、IPも隠しません。この種のルート最適化ツールは何年も使われてきました。とはいえアンチチートの方針と利用規約は各パブリッシャーが定めるもので、いつでも変わり得ます。BANが絶対に起きないと保証できるツールはありません。プレイ前に該当ゲームの規約を確認してください。

実際どれくらいpingが下がる?

場所とISPによります。ISPが通信を非効率な経路に通している場合 (非常によくあります) は、LightSpeedがpingをそれなりに削れます。すでに最適な経路なら改善はわずかかもしれません。モデルは最良のルートを選び、直接経路が最速ならそれを選びます。上のヒーロー指標は実際のクライアント計測に基づく推定値で、クライアントからゲームサーバーへのICMP往復とトンネル経由のゲーム通信往復の差です。ICMPとゲーム通信は別の物差しなので、約束ではなく目安として読んでください。

LightSpeedでインターネットは速くなる?

いいえ。LightSpeedは通信そのものを速くはできません。物理法則には勝てません。できるのは、通信を利用可能な最速の経路に先回りして流し、混雑や不必要な遠回りを避けることです。ISPがすでにクリーンな経路を持っていたり、プロキシの位置が悪かったりすると、改善はほとんど実感できないでしょう。

プロキシを使うとpingが上がるのはなぜ?

通常は次のどちらかです。(1) プロキシがゲームサーバーよりも遠く、余分なホップがレイテンシを増やしている、または (2) プロキシのデータセンターがインターネットバックボーンに十分接続されていない。プロキシの設置場所は重要で、データセンターが主要なバックボーン／ピアリング拠点にどれだけ近いかが効きます。実際の経路は BGP ピアリング契約や ISP の優先制御にも左右され、これはあなたにも LightSpeed にも制御できません。自分に近いプロキシではなく、ゲームサーバー に最も近いプロキシを選んでください。経路の仕組みを対話的に見るには ルート可視化 をご覧ください。

対応しているゲームは?

現在 22 タイトル：Fortnite、CS2、CS:GO Legacy、Dota 2、Rust、Valorant、Apex Legends、Overwatch 2、League of Legends、PUBG、MapleStory、Genshin Impact、Rocket League、World of Tanks、Dead by Daylight、Bodycam、Roblox、Project Zomboid、WARDOGS、Minecraft、Hunt: Showdown、Rainbow Six Siege にプロファイルが組み込まれています。--game <name> で起動するか、自動検出に任せるだけです。その他の UDP ベースのゲームも、手動でポートを設定すれば利用できます。

データは安全?

匿名の集計テレメトリーは既定で有効です。アカウントも登録も不要で、個人データも扱いません。送信するのは集計されたネットワーク指標（レイテンシのパーセンタイル、ジッター、FEC カウンター）のみで、リレーの認証なし /telemetry エンドポイントへ平文 HTTP で送られます。IP アドレス、識別子、パケット内容は含みません。セルは 3 件以上の報告が集まるまで公開されません（数えるのは報告数であり、人数ではありません）。--no-telemetry、lightspeed.toml の telemetry = false、または GUI のチェックボックスでいつでもオフにできます。オーバーヘッドを増やさないため、すべての通信は暗号化されずに通過します。プライバシーポリシー と データ辞書 をご覧ください。

プロキシノードはどう入手する?

最も簡単なのは何もしないことです。既定のクライアントはコミュニティリレーネットワークを使い、署名済みレジストリ から最速のリレーを自動的に見つけます。自分でノードを運用したい場合は、Vultr で月額 5〜6 ドルの VPS を立て（または Oracle Cloud の無料枠を利用し）、リポジトリの setup-new-node.sh スクリプトを実行して、クライアントをご自身の IP に向けてください。所要時間は約 5 分です。データ・制御・ヘルス用のポートは、プロキシ設定の [network] セクションで変更できます。詳しい手順は infra/README.md をご覧ください。

なぜRustなのか?

RustはC/C++の性能とメモリ安全の保証を両立させます。毎秒数千パケットを扱う遅延重視のネットワークツールには、ゼロオーバーヘッドの抽象化が必要です。Rustのasyncエコシステム (Tokio) とQUICライブラリ (quinn) は世界最高水準です。

MLルーティングの仕組みは?

11個の特徴量を使いネットワーク遅延データでRandom Forestモデルを学習します: 現在の遅延、過去のp50/p95、ジッター、パケットロス、ホップ数、時間帯、プロキシ負荷、地理的距離。モデルは1回の推論パスで最速のプロキシルートを予測し、実行時の計測はマイクロ秒単位です。学習のたびに、モデルはホールドアウトしたテスト分割に対して自身のR²、MAE、RMSEを報告します。この数値は学習データによって変わるため、固定の値は公開していません。
