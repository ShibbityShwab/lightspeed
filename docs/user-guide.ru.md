# Руководство пользователя LightSpeed

> Пошаговые инструкции по снижению пинга с помощью LightSpeed.

---

## Как работает LightSpeed

Ваш провайдер направляет игровой трафик по маршрутам, оптимизированным под стоимость, а не под скорость. LightSpeed перехватывает UDP-пакеты игры и туннелирует их через **релей** - легкий сервер в дата-центре с высокоскоростными магистральными подключениями к регионам игровых серверов. По умолчанию вы используете **сеть общественных релеев** (восемь релеев, оплаченных спонсорами, обнаруживаются автоматически через подписанный реестр, настройка не требуется). Также можно поднять собственный прокси. Если этот путь быстрее стандартного маршрута вашего провайдера, пинг падает.

```
Ваш ПК ──→ Провайдер (медленный путь) ──→ Игровой сервер        ❌ Высокий пинг
Ваш ПК ──→ Прокси LightSpeed (быстрая магистраль) ──→ Игровой сервер   ✅ Низкий пинг
```

---

## Требования

- CLI-утилита `lightspeed` или `lightspeed-gui` (Windows). Настройка прокси не нужна: клиент находит общественные релеи автоматически.
- Для режима перехватчика: права root/Администратора
- Необязательно: собственная прокси-нода, если предпочитаете самостоятельный хостинг (см. [Развертывание прокси](deploy-proxy.md))

## Какое приложение мне нужно?

| Вы на | Скачать | Почему |
|-----------|----------|-----|
| **Windows** | `lightspeed-gui` (MSI или ZIP) | GUI - самостоятельное приложение: в него уже входят движок клиента и драйвер WinDivert. CLI вам **не** нужен. |
| **Linux** | `lightspeed-gui` (или `lightspeed-client`) | GUI работает на Linux (системный трей - заглушка); CLI для опытных пользователей. |
| **macOS** | `lightspeed-client` | Проверенного GUI пока нет. GUI собирается для macOS, но **не протестирован** на реальном железе. |
| **Хостинг прокси** | `lightspeed-proxy` | Только если вы запускаете релей-ноду на VPS. |

> **Вам всегда нужен всего один пакет.** Если вы играете на Windows, возьмите `lightspeed-gui` и забудьте про остальное. `lightspeed-client` - для опытных пользователей Linux и игроков на macOS; `lightspeed-proxy` - для тех, кто хостит сам.

## Быстрый старт (CLI - все платформы)

### 1. Проверьте окружение

```bash
lightspeed --check
```

Проверяет, есть ли в вашей ОС нужные инструменты фильтрации пакетов (nftables/iptables в Linux, pfctl в macOS, WinDivert в Windows).

### 2. Прощупайте релеи

```bash
lightspeed --probe-proxies
```

Показывает задержку до каждого обнаруженного релея. При первом запуске клиент сам выбирает самый быстрый; вы можете переопределить выбор, взяв релей ближе к вашему **игровому серверу**, а не к вашему местоположению.

### 3. Запустите перехватчик

```bash
# Linux/macOS (требуется root)
sudo lightspeed --start-interceptor --game rust --proxy YOUR_PROXY_IP:4434

# Windows (требуется Администратор)
lightspeed --start-interceptor --game rust --proxy YOUR_PROXY_IP:4434
```

### 4. Запустите игру

Подключайтесь к любому серверу как обычно. LightSpeed определяет игровой сервер по исходящим пакетам и начинает туннелирование за считанные секунды.

### 5. Следите за работой

CLI показывает статистику в реальном времени:
```
⚡ OPTIMIZING - 123.45.67.89:28015
Packets Sent: 142 | Packets Returned: 139 | Packets Delivered: 139
```

## Быстрый старт (GUI - Windows)

### 1. Скачайте

Возьмите последний релиз со страницы [Releases](https://github.com/ShibbityShwab/lightspeed/releases). Распакуйте все файлы - держите `WinDivert64.sys` и `WinDivert.dll` рядом с `lightspeed-gui.exe`.

### 2. Запустите от имени Администратора

Щелкните правой кнопкой по `lightspeed-gui.exe` → **Запуск от имени администратора**. Перехватчику нужен доступ на уровне ядра (как и VPN-софту).

### 3. Выберите релей и игру

GUI находит общественные релеи и при первом запуске сам выбирает самый быстрый. Релей можно переопределить в выпадающем списке, затем выберите игру.

### 4. Нажмите **⚡ OPTIMIZE MY ROUTE**

Статус сменится на "🎯 Finding your game server…"

### 5. Запустите игру

Подключитесь к любому серверу. LightSpeed определит его за секунды.

---

### GUI для macOS (не протестирован)

GUI собирается для macOS, но **не протестирован** на реальном железе. В релизе
лежит голый `tar.xz` (cargo-dist 0.32 не умеет `.app`/`.dmg`), поэтому чтобы
получить полноценный бандл, запустите на Mac:

```bash
cargo build --release -p lightspeed-gui
./tools/package-macos.sh 1.6.5
```

Так создаются `LightSpeed.app` и `LightSpeed-1.6.5.dmg`. Приложение подписано
ad-hoc, поэтому при первом запуске нужно щелкнуть правой кнопкой → Открыть (или
`xattr -dr com.apple.quarantine LightSpeed.app`).

## Как выбрать правильный релей

| Вы находитесь | Игровой сервер | Лучший регион релея |
|-----------|---------------|-------------------|
| Австралия | Запад США | Запад США (Лос-Анджелес) |
| Европа | Восток США | Восток США (Нью-Джерси) |
| Юго-Восточная Азия | Сингапур | Сингапур |
| Южная Азия | Индия | Мумбаи |
| Восточная Азия | Япония | Токио |
| Южная Америка | Восток США | Восток США (Нью-Джерси) |
| Где угодно | Тот же регион | Ближайший к игровому серверу |

> **Практическое правило:** выбирайте релей ближе к **игровому серверу**, а не к себе. Ваш трафик идет ПК → релей → игровой сервер, поэтому важнее всего участок релей - игровой сервер.

## Прямая коррекция ошибок (FEC)

FEC добавляет около 25% накладных расходов на трафик, чтобы восстанавливать потерянные пакеты без повторной передачи.

**Включайте, когда:**
- У вас есть потери пакетов (микрорывки, откаты назад)
- Вы на Wi-Fi с периодическими помехами

**Отключайте, когда:**
- Ваше соединение и так загружено под завязку
- У вас тарифицированное или лимитированное соединение
- Потери пакетов меньше 0.1% (пользы нет)

```bash
# CLI: включить FEC с размером блока по умолчанию (K=4)
lightspeed --start-interceptor --game cs2 --proxy YOUR_PROXY:4434 --fec

# Свой размер блока (K=8 → 12.5% накладных расходов)
lightspeed --start-interceptor --game cs2 --proxy YOUR_PROXY:4434 --fec --fec-k 8
```

## Для продвинутых: ручной режим сервера

Если автоопределение не срабатывает (нестандартные порты, необычная игра):

```bash
# Режим перенаправления: игра подключается к localhost, LightSpeed перенаправляет на реальный сервер
lightspeed --game rust --game-server 123.45.67.89:28015 --proxy YOUR_PROXY:4434
```

Затем настройте игру на подключение к `127.0.0.1:<port>` (локальный порт, который печатает LightSpeed).

---

## Смена серверов во время сессии

LightSpeed сам замечает, когда вы отключаетесь от одного сервера и подключаетесь к другому. Статус ненадолго показывает "🎯 Finding your game server…" и захватывает новый адрес. Ничего делать вручную не нужно.

## Системный трей (GUI для Windows)

- Нажмите **×**, чтобы свернуть в трей (не завершает работу)
- Дважды щелкните по значку молнии, чтобы восстановить окно
- Правый щелчок открывает быстрые действия Подключить / Отключить / Выход
