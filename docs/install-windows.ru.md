# Установка LightSpeed в Windows

Windows - платформа, где главное приложение это GUI. Пакет `lightspeed-gui` представляет собой отдельное приложение, в которое уже входят движок клиента и драйвер WinDivert, так что отдельный клиент скачивать не нужно никогда.

---

## Что скачать

Возьмите последний релиз со [страницы Releases](https://github.com/ShibbityShwab/lightspeed/releases/latest). Для Windows x86_64 (все современные ПК на Intel и AMD) выберите одно из:

| Файл | Когда использовать |
|------|-------------|
| `lightspeed-gui-...-windows-msvc.msi` | Рекомендуется. Устанавливается в Program Files, добавляет ярлык в меню Пуск и регистрирует деинсталлятор. |
| `lightspeed-gui-...-windows-msvc.zip` | Портативный. Распакуйте куда угодно и запустите `lightspeed-gui.exe`. |

Оба содержат один и тот же GUI плюс `WinDivert.dll` и `WinDivert64.sys`.

> **Windows на ARM64 пока не является публикуемой целью сборки.** Релизы собираются под `x86_64-pc-windows-msvc`. На устройстве с ARM64 сборка x86_64 работает через слой эмуляции Windows, но на реальном железе ARM64 она не протестирована.

### CLI для Windows (без поддержки)

Сборка командной строки для Windows тоже публикуется в виде zip (`lightspeed-client-...-windows-msvc.zip`). Она предназначена для скриптов и работы без интерфейса, но **не поддерживается**: рекомендуемый путь в Windows - GUI. Если используете ее, запускайте из терминала с повышенными правами (см. ниже).

---

## Установка (MSI)

1. Скачайте `.msi`.
2. Дважды щелкните по нему и пройдите мастер. Windows SmartScreen может предупредить о неизвестном издателе; релиз заверен через Sigstore, так что при желании можно проверить аттестацию.
3. Запустите **LightSpeed** из меню Пуск.

## Установка (портативный zip)

1. Скачайте `.zip`.
2. Щелкните по нему правой кнопкой, выберите **Извлечь все** и распакуйте в папку, в которую можно писать (например `C:\LightSpeed`). Не запускайте его прямо из архива.
3. Запустите `lightspeed-gui.exe`.

---

## Права администратора

LightSpeed использует драйвер WinDivert для перехвата игрового UDP-трафика. WinDivert требует прав **Администратора**.

- GUI запрашивает повышение прав, когда нужно запустить перехватчик. Примите запрос UAC.
- Если запускаете сборку CLI, открывайте ее из терминала с правами **Администратора** (щелкните правой кнопкой по Windows Terminal или PowerShell, затем **Запуск от имени администратора**).

Без повышения прав перехватчик не сможет подключиться, и вы увидите ошибку перехватчика в окне статуса.

---

## Первый запуск

1. Запустите GUI и примите запрос UAC.
2. GUI сам находит общественные релеи через подписанный реестр. Адрес прокси не нужен.
3. Выберите игру из списка игр.
4. Запустите перехватчик, затем запустите игру и подключитесь к серверу.

GUI показывает статус релея, состояние регистрации и счетчики пакетов, так что видно, как идет трафик.

---

## Проверка работы

**Проверьте обнаружение и регистрацию релеев.** Откройте окно статуса GUI. Вы должны увидеть список общественных релеев (Los Angeles, New Jersey, Singapore, Frankfurt, Tokyo, Mumbai, Madrid, Sydney) со здоровым статусом и строку регистрации, показывающую, что рукопожатие QUIC/auth прошло успешно. Если используете сборку CLI, выполните:

```powershell
lightspeed-client.exe --probe-proxies
```

Это выполняет один проход обнаружения и прощупывания и печатает наглядный отчет со списком каждого найденного релея и его задержкой. Вы должны увидеть все восемь общественных релеев.

**Проверьте регистрацию в плоскости управления.** Со сборкой CLI:

```powershell
lightspeed-client.exe --test-control
```

Это подключается к плоскости управления QUIC, регистрирует сессию, пингует и отключается, печатая результат каждого шага. Успешная регистрация доказывает, что плоскость управления доступна и аутентификация работает.

**Проверьте поток пакетов.** В GUI счетчики пакетов должны расти, как только игра подключится к серверу. Если "Packets Sent" остается на 0, перехватчик пока не видит игровой трафик; см. [Устранение неполадок](troubleshooting.md).

## Журналы

GUI пишет журнал трассировки в:

```
%LOCALAPPDATA%\Lightspeed\gui-trace.log
```

Вставьте этот путь в адресную строку Проводника, чтобы открыть его. Приложите его к отчету об ошибке, если что-то пойдет не так. О значении строк журнала см. [Устранение неполадок](troubleshooting.md).

---

## Удаление

- **MSI:** Параметры → Приложения → Установленные приложения → LightSpeed → Удалить.
- **Zip:** удалите распакованную папку. Файл журнала в `%LOCALAPPDATA%\Lightspeed\` остается; удалите его вручную, если хотите полностью чистое удаление.
