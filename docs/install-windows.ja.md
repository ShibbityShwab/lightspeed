# Windows に LightSpeed をインストールする

Windows は GUI を優先するプラットフォームです。`lightspeed-gui` パッケージは単体アプリで、クライアントエンジンと WinDivert ドライバーがすでに入っているので、別途クライアントをダウンロードする必要はありません。

---

## ダウンロードするもの

[Releases ページ](https://github.com/ShibbityShwab/lightspeed/releases/latest) から最新リリースを入手します。Windows x86_64（現行の Intel と AMD の PC すべて）では、次のどちらかを選びます。

| ファイル | 使う場面 |
|------|-------------|
| `lightspeed-gui-...-windows-msvc.msi` | 推奨。Program Files にインストールし、スタートメニューのショートカットを追加し、アンインストーラーを登録します。 |
| `lightspeed-gui-...-windows-msvc.zip` | ポータブル版。どこにでも展開して `lightspeed-gui.exe` を実行します。 |

どちらにも同じ GUI と `WinDivert.dll` および `WinDivert64.sys` が入っています。

> **Windows on ARM64 はまだ公開ターゲットではありません。** リリースビルドのターゲットは `x86_64-pc-windows-msvc` です。ARM64 端末では x86_64 ビルドが Windows のエミュレーション層で動きますが、実際の ARM64 ハードウェアでは未検証です。

### Windows の CLI（サポート対象外）

Windows 用のコマンドラインビルドも zip（`lightspeed-client-...-windows-msvc.zip`）として公開されています。スクリプトやヘッドレス用途向けに提供されていますが、**サポート対象外** です。Windows では GUI が推奨の経路です。これを使う場合は、管理者権限のターミナルから実行してください（下記参照）。

---

## インストール（MSI）

1. `.msi` をダウンロードします。
2. ダブルクリックしてウィザードに従います。Windows SmartScreen が不明な発行元について警告するかもしれません。このリリースは Sigstore で証明されているので、必要なら証明を検証できます。
3. スタートメニューから **LightSpeed** を起動します。

## インストール（ポータブル zip）

1. `.zip` をダウンロードします。
2. 右クリックして **すべて展開** を選び、書き込みできるフォルダー（たとえば `C:\LightSpeed`）に展開します。zip の中から直接実行しないでください。
3. `lightspeed-gui.exe` を実行します。

---

## 管理者権限

LightSpeed は WinDivert ドライバーを使ってゲームの UDP 通信を横取りします。WinDivert には **管理者** 権限が必要です。

- GUI はインターセプターを起動する必要があるときに昇格を要求します。UAC のプロンプトを承認してください。
- CLI ビルドを使う場合は、**管理者** のターミナルから起動します（Windows Terminal か PowerShell を右クリックし、**管理者として実行** を選びます）。

昇格しないとインターセプターは接続できず、ステータス画面にインターセプターのエラーが表示されます。

---

## 初回起動

1. GUI を起動し、UAC のプロンプトを承認します。
2. GUI は署名付きレジストリを通じてコミュニティリレーを自動で見つけます。プロキシアドレスは不要です。
3. ゲーム一覧から自分のゲームを選びます。
4. インターセプターを起動し、ゲームを起動してサーバーに接続します。

GUI はリレーの状態、登録状況、パケットカウンターを表示するので、通信が流れているかを確認できます。

---

## 動作を確認する

**リレーの検出と登録を確認する。** GUI のステータス画面を開きます。コミュニティリレー（ロサンゼルス、ニュージャージー、シンガポール、フランクフルト、東京、ムンバイ、マドリード、シドニー）が正常な状態で一覧表示され、QUIC と認証のハンドシェイクが成功したことを示す登録の行が見えるはずです。CLI ビルドを使っている場合は次を実行します。

```powershell
lightspeed-client.exe --probe-proxies
```

1 回の検出とプローブを行い、見つけた各リレーとその遅延を一覧にしたレポートを表示します。8 台のコミュニティリレーすべてが見えるはずです。

**コントロールプレーンの登録を確認する。** CLI ビルドでは次を実行します。

```powershell
lightspeed-client.exe --test-control
```

これは QUIC コントロールプレーンに接続し、セッションを登録し、ping を送り、切断します。各手順の結果を表示します。登録が成功すれば、コントロールプレーンに到達でき、認証も動いている証拠になります。

**パケットの流れを確認する。** GUI で、ゲームがサーバーに接続されるとパケットカウンターが増えていくはずです。「Packets Sent」が 0 のままだと、インターセプターがまだゲームの通信をとらえていません。[トラブルシューティング](troubleshooting.md) を参照してください。

---

## ログ

GUI はトレースログを次に書き出します。

```
%LOCALAPPDATA%\Lightspeed\gui-trace.log
```

このパスをエクスプローラーのアドレスバーに貼り付けると開けます。問題が起きたら不具合報告に添付してください。ログの各行の意味は [トラブルシューティング](troubleshooting.md) にあります。

---

## アンインストール

- **MSI:** 設定 → アプリ → インストールされているアプリ → LightSpeed → アンインストール。
- **Zip:** 展開したフォルダーを削除します。`%LOCALAPPDATA%\Lightspeed\` のログファイルは残るので、きれいに消したい場合は手動で削除してください。
